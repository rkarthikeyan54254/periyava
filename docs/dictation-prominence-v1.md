# Dictation discoverability v1

The Ask Mahaperiyava composer keeps dictation optional, editable, and never auto-submitting while making voice input easier to discover for family-beta users.

- A bilingual prompt appears above the question field.
- The Dictate control receives a microphone cue, stronger contrast, and a larger touch target.
- On narrow screens, Dictate and Seek guidance receive equal-width touch targets.
- Existing speech-recognition behavior and evidence lookup behavior are unchanged.
